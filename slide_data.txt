----------------------------------------------------------------
5. MAPPING PIPELINE
----------------------------------------------------------------

Stack:
  Road network      : OpenStreetMap (via osmnx)
  GPS snapping      : osmnx nearest_edges (UTM projection)
  Spatial data      : GeoPackage (.gpkg) via geopandas
  Map rendering     : Folium (Python) / Leaflet.js (browser)
  Base tiles        : CartoDB Positron

Aggregation modes:
  Pessimistic       : worst label observed on a segment wins
  Majority vote     : most common label wins (ties → worst)

Pipeline steps:
  1. OCR (pytesseract)       → GPS + speed from dashcam overlay
  2. process_frames.py       → filter idle/anomaly, copy frames
  3. classify_dataset.py     → run classifier on filtered frames
  4. snap_to_roads.py        → snap GPS points to OSM edges
  5. render_map.py           → interactive HTML map

Dataset coverage:
  Cameras           : 4
  Raw frames (OCR)  : ~34,000 per camera
  After filtering   : ~26,000 per camera
  Road segments mapped (3-class) : 808


----------------------------------------------------------------
6. KEY FINDINGS FROM TUNING
----------------------------------------------------------------

- Swin Transformer (small) was the clear winner across all phases
- Lower learning rate (3e-5) works best — Swin is LR-sensitive
- Freezing backbone layers hurts performance on this dataset
- Label smoothing and class weighting gave no benefit
- Biggest accuracy gain: class merging 5→3 classes (+28% accuracy)
- 5-class model kept for presentation comparison (53% acc, 57% F1)
